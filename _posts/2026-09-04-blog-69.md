## Key Points

- Vercel's Fluid compute is a unified system that automatically assembles the right computing environment for any workload, eliminating the need to provision different infrastructure for different tasks
- Fluid runs builds, sandboxes, and functions as different shapes of the same underlying system, currently handling 15M builds/day, 25M sandboxes/week, and 1T requests/month
- The system works by assembling machines to fit the 'shape' of incoming workloads - builds get CPU-heavy machines, functions get IO-optimized machines, sandboxes get flexible configurations
- Hive is Vercel's hardware control system that provisions isolated VMs in milliseconds, choosing the right machine for each job and maintaining strong isolation in a multitenant environment
- Fluid Images allow developers to push their own container images to Vercel's registry, which get converted to an optimized boot format (VHS) for millisecond startup times
- Vercel Drives provide portable, durable storage that travels with workloads instead of being stranded on individual machine disks, enabling state persistence across compute sessions
- The unified architecture means improvements to one compute type (like boot time or caching) benefit all products simultaneously rather than needing separate optimization
- Fluid is particularly effective for AI agents, which need rapid, secure provisioning of custom environments for running untrusted code with persistent state
- Unlike traditional cloud infrastructure where you adapt your work to fixed machines, Fluid adapts machines to fit the specific requirements of each workload

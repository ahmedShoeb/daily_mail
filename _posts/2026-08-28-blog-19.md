## Key Points

- IBM Granite 4.2 is a new family of reasoning-focused large language models released in three sizes: 3B, 8B, and 30B parameters
- All models are pre-trained from scratch on approximately 15 trillion tokens using a five-phase training strategy that extends context windows to 512K tokens
- Features a unique 'thinking/non-thinking' switch with a low-effort thinking mode that allocates reasoning resources based on task difficulty
- Models undergo supervised fine-tuning on chain-of-thought, reasoning, and agentic-trajectory data followed by multi-stage reinforcement learning
- The 8B and 30B models receive additional agentic RL training to learn tool calling, code editing, terminal operation, and web search in real sandboxed environments
- All models support native tool calling with OpenAI-compatible API endpoints and are released under the Apache 2.0 license
- Performance scales with model size across reasoning, agentic coding, instruction following, and long-context tasks
- Includes quantized variants for inference optimization and supports multiple programming languages
- Trained on NVIDIA GB200 NVL72 clusters with CoreWeave infrastructure using NeMo-RL and NeMo-Gym frameworks

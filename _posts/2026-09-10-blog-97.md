## Key Points

- Lovable.dev has introduced a new 'Drafts' feature that allows builders to create experimental copies of their projects
- Drafts serve as separate playgrounds with their own chat and preview functionality, enabling parallel exploration of different project versions
- Changes made in drafts only become live when users explicitly accept and publish them, keeping the original project intact
- The feature addresses previous collaboration challenges where multiple users had to wait their turn or create full project remixes
- Teams can invite collaborators to work on drafts without affecting the live app, maintaining control over what gets published
- Multiple drafts can be created simultaneously to explore different design directions, layouts, colors, fonts, and content variations
- Current draft functionality focuses on front-end changes (design, layout, copy) while database structure and login setup changes still happen in the project's main chat
- Drafts work on any project regardless of whether it has a database, providing flexibility for different types of applications
- Users can create unlimited drafts, switch between them to compare versions, and easily delete or start over if not satisfied
- This represents the first version of drafts, with the company actively seeking user feedback for future improvements

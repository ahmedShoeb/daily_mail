## Key Points

- Qwen 3.8 27B is a new Apache 2 licensed 27B parameter vision-capable LLM from Alibaba's Qwen research lab
- The model defaults to 'xhigh' reasoning effort, which causes it to dramatically overthink even simple tasks like drawing basic SVGs
- Despite being a relatively small 17GB model, it demonstrates impressive capabilities including vision tasks, code generation, and bounding box detection
- The author found it performs well on consumer hardware like a 128GB M5 Max MacBook Pro and NVIDIA DGX Spark
- Performance is the main limitation - the model runs at 15-30 tokens/second, which feels slow compared to hosted API models
- The model supports Multi-Token Prediction, which when enabled provides around 72% performance improvement
- It can successfully run coding agents and build functional tools despite its smaller size
- The article demonstrates how much progress local models have made, with capabilities that would have been competitive with top proprietary models a year ago

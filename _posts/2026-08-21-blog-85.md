## Key Points

- GLM-5.3, the new open source language model from Chinese startup z.ai, is now available via API after a notable debut where it reportedly found a previously undetected vulnerability in Cursor
- The API pricing remains unchanged from GLM-5.2 at $1.40 per million input tokens and $4.40 per million output tokens, making it competitively priced against frontier models
- Cached input costs $0.26 per million tokens, with cached-input storage currently free for a limited time
- GLM-5.3 scores 60 on Artificial Analysis's Intelligence Index, tying Kimi K3 as the top performing open weights model globally, and scoring seven points higher than GLM-5.2
- The model's total cost per million tokens (input + output) is $5.80, compared to $8 for Grok 4.6, $18 for Kimi K3, $30 for Claude Opus 5, and $35 for GPT-5.6 Sol
- Despite identical token prices to GLM-5.2, GLM-5.3 costs about $0.68 per Intelligence Index task versus roughly $0.44 for GLM-5.2 due to being more verbose
- The model currently supports the OpenAI Chat Completions-compatible protocol for developers with GLM Coding Plan subscriptions
- Z.ai plans to make the model's weights openly available, though specific timing and licensing details haven't been announced

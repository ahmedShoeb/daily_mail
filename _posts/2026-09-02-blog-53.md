## Key Points

- vLLM v0.28.0 is a massive release with 584 commits from 270 contributors, including 76 new contributors
- Major Kimi-K3 performance push across the stack including Decode Context Parallel (DCP) support and 1.5-3x kernel-level speedup
- DeepSeek V4 now has end-to-end sparse MLA support for plain decode, MTP, and DSpark speculative decoding
- Enhanced speculative decoding with DFlash2 local convolution and confidence-scheduled verification
- Model Runner V2 has matured with E/P/D disaggregation, weight offloading, and multi-layer MTP KV cache support
- New default settings: max_num_batched_tokens increased from 8192 to 16384, prefix caching enabled by default for Mamba models
- Expanded hardware support including AMD ROCm support for Kimi-K3 and improved Intel XPU capabilities
- Security fixes including DoS vulnerability patching and improved audio decode duration guards
- Breaking changes: bitsandbytes support migrated to an out-of-tree plugin, Transformers bumped to 5.15.0
- New models supported: Muse Glimmer, Ling 3.0 Flash, Dots3 NOTE, and enhanced Qwen support

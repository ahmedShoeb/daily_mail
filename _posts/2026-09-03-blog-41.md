## Key Points

- ZCode is Z.ai's desktop coding agent that functions as an Agentic Development Environment (ADE), allowing developers to give tasks to an AI agent that plans work, edits files, runs commands, and verifies results
- The agent is built around GLM-5.3, a model from Chinese AI lab Zhipu AI that's been specifically trained for long engineering tasks with a 1M token context window and improved security vulnerability detection
- ZCode offers four permission modes (Ask before changes, Edit automatically, Plan mode, and Full access) to control how much autonomy the agent has
- The service includes features like automations for scheduled tasks, phone control via WeChat/Telegram, and a Plugin Marketplace for additional capabilities
- Pricing starts at $18/month for the Lite plan, with Pro at $80/month and Max at $168/month (all currently 30% off)
- GLM-5.3 shows competitive performance with closed models but uses fewer tokens and costs less, scoring 84.5% on CyberGym security benchmarks
- Z.ai provides open weights for GLM-5.3, though with a custom license (not MIT) that requires security review for companies earning over $10 billion annually
- The author recommends ZCode as a useful second opinion tool for code review, security scanning, and automation, but advises caution with proprietary code due to data privacy considerations

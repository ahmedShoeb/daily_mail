## Key Points

Arm announced three major IP updates: C2-Ultra CPU, G2-Ultra NX GPU, and Neoverse CSS N4 server platform
C2-Ultra CPU shows minimal architectural changes from previous Cortex X925 with same 10-wide decode, 8 simple ALUs, and 6 FP lanes
Arm claims 15% peak performance uplift for C2-Ultra over C1-Ultra, but analysis reveals only 3.2% IPC improvement after factoring clock speed increases
The performance comparisons include 8.5% higher clock speeds and 3MB L2 cache on C2-Ultra platform, making true microarchitectural improvements unclear
G2-Ultra NX GPU features the 'largest re-architecting in 7 generations' with new matrix accelerators for AI workloads
G2-Ultra NX adds desktop GPU features like Opacity Micromaps and introduces Neural Super Sampling (NSS) for AI upscaling
The GPU's matrix accelerators only support INT8 and INT16 precision, missing FP8 and BF16 formats popular in ML workloads
Xiaomi's XRING O3 chip already implements G2-Ultra NX but only includes matrix accelerators in half of its shader cores
Neoverse CSS N4 server platform supports 8-128 cores per die, up to 3.8GHz frequency, and includes up to 256MB shared cache
The article criticizes Arm for poor technical disclosure in this announcement, with many important details only available through follow-up questions

## Key Points

- xAI has expanded access to Grok Bot, making it available with all SuperGrok, Cursor Pro, and Cursor Teams plans
- Grok Bot is now included with SuperGrok, SuperGrok Plus, SuperGrok Heavy, Cursor Pro, Cursor Pro+, Cursor Ultra, and Cursor Teams plans
- Grok Bot has its own separate usage limits, so tasks assigned to Bots don't count against existing Grok and Cursor plan usage
- Grok Bot functions as digital teammates that can handle projects or entire functions, working across apps and inboxes
- Users can run multiple Bots simultaneously in parallel, even putting them in group chats to pass work between themselves
- Bots have their own cloud-based computer with browser and terminal access, allowing them to sign into apps and work directly in the actual tools
- Grok Bot features a text-thread interface that works seamlessly across mobile and desktop without setup requirements
- The system allows easy setup of routines where Bots can learn by watching users perform tasks once, then run autonomously
- xAI demonstrated several practical use cases including sales prospecting, website building, digital decluttering, customer support, game asset creation, office management, inbox management, meeting stand-ins, and refund management
- Enterprise users can join a waitlist for larger team and company rollouts as xAI ramps up access

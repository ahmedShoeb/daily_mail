## Key Points

- Meta Superintelligence Labs introduces Muse Voice Transcribe, their first real-time audio perception model
- The model delivers real-time streaming ASR (automatic speech recognition) with adaptive delay technology
- Features diarization supporting 20+ speakers simultaneously and endpointing capabilities
- Multilingual support for 25+ languages with seamless code-switching between languages
- Can utilize language, keyword, and context biasing for improved accuracy
- Ranks first on Artificial Analysis for streaming speech-to-text and public diarization benchmarks
- Processes audio in 80ms chunks (12.5 Hz) and transforms each into a single soft token
- Uses reinforcement learning for adaptive delay to balance accuracy and latency
- Supports long audio inputs exceeding one hour with no required post-processing
- Now powers voice dictation across Meta AI and Muse Code applications

## Key Points

- Anthropic has merged Claude's chat and Cowork memory systems, making shared memory the default setting for all conversations
- Information is now captured and added to memory in real-time during conversations, rather than waiting until conversations end
- The feature is enabled by default for consumer users on Free, Pro, and Max plans across web, desktop, and mobile platforms
- Users can review, edit, or delete memories through Topics in the memory settings, with corrections applying everywhere afterwards
- By default, Claude does not store information on sensitive topics like health, race, ethnicity, religious beliefs, politics, or gender identity
- Sensitive topics can be manually enabled by users, but certain categories like social security numbers and criminal history remain permanently excluded
- Team and Enterprise customers have memory turned off by default, with admins controlling availability for compliance purposes
- The update makes Claude feel like one continuous assistant rather than separate products, but Claude Code remains a separate memory system
- The consolidation reflects competitive pressure in the AI assistant space, where memory creates switching costs for users

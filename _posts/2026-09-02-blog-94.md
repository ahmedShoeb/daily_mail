## Key Points

- NVIDIA has released a quantized version of DeepSeek AI's DeepSeek-V4-Pro-0813 model called DeepSeek-V4-Pro-0813-NVFP4
- The model is an autoregressive Mixture-of-Experts language model with 1.65 trillion total parameters and 49 billion activated parameters
- This is quantized using NVIDIA's Model Optimizer to NVFP4 data type, specifically optimized for NVIDIA Blackwell B200 hardware
- The model maintains strong performance across multiple benchmarks including reasoning, long-context recall, agentic tool-use, and coding tasks
- It supports a massive 1 million token context length and includes DeepSeek's DSpark speculative decoding module
- The model is ready for commercial or non-commercial use with global deployment availability
- NVIDIA notes this is a third-party model developed by DeepSeek AI, not created by NVIDIA itself
- The quantization process involves three stages: resharding the checkpoint, collecting activation ranges, and exporting the NVFP4 checkpoint
- Benchmarks show minimal accuracy loss compared to the original MXFP4 version across various evaluation datasets
- The model is particularly suited for advanced reasoning, agentic AI applications, tool use scenarios, and complex problem-solving

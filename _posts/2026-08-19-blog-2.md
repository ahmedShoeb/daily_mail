## Key Points

- GLM-5.3 represents a significant upgrade from GLM-5.2, achieving all improvements through post-training alone without changing the base model
- The model shows dramatic improvements in complex coding tasks, more than doubling performance on benchmarks like Terminal-Bench 3.0 (4.6% to 28.3%) and DeepSWE v1.1 (46.2% to 66.9%)
- GLM-5.3 demonstrates emergent cyber security capabilities, identifying 2,436 real-world vulnerabilities across 269 projects including 1,097 medium-to-high severity issues
- The oldest discovered vulnerability dates back to 1981, with vulnerabilities having remained undetected for an average of 26.6 years before discovery
- The model features new training environments that simulate real engineering workflows rather than coding exercises, including multi-day tasks requiring end-to-end ownership
- Three thinking effort levels are now supported (low, high, max) with thinking capability mandatory - disabled mode is no longer available
- GLM-5.3 achieves better performance while using fewer output tokens compared to GLM-5.2, showing improved efficiency
- The model shows strong performance against competitors, leading on some benchmarks like CyberGym (84.5% vs competitors' 83.8% or lower)
- Model weights will be publicly available in two weeks, with GLM-5.3 already deployed to GLM Coding Plan subscribers
- The Z.ai Security Disclosure Ledger has been created to publicly track vulnerability findings through the disclosure process

## Key Points

Hugging Face has released @huggingface/kernels, a library containing 207 optimized WebGPU kernels for local AI inference in browsers
Each kernel is published as a complete package with interfaces, shader templates, correctness cases, benchmarks, and usage instructions on the Hugging Face Hub
The company also launched Fleet - an in-browser GPU benchmarking tool that crowdsources performance data from real-world devices
The kernels show significant performance improvements, being 2.57x faster on average compared to ORT WebGPU, with some operations showing 10,000x speedups
WebGPU kernels are foundational for fast browser inference since higher-level runtimes depend on efficient GPU operations
Each kernel repository includes manifest.json for operation contracts, test.json for correctness verification, and bench.json for performance evaluation
The library supports operations across various machine learning architectures and workloads with explicit versioning and contracts
Kernels can be loaded directly from the Hub using npm package @huggingface/kernels@preview
The collection sits alongside kernels for other platforms (CUDA, ROCm, Metal) on the Hugging Face Hub
This release represents the foundation for Hugging Face's broader browser inference stack and WebAI ecosystem

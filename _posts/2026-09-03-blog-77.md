## Key Points

- The author proposes 'memoryfields' as a simpler alternative to current agent memory systems that treat memory as a process rather than data
- Memoryfields use a portable file format with Markdown pages, optional YAML frontmatter, and optional SQLite vector index for semantic search
- Current memory systems are criticized for being too complex, tying users to specific platforms, or being overly 'High Modernist' with graphs that strip context
- Key design decisions: using prose instead of chunks, semantic search instead of graph walking, 'low mechanism' approach for model scaling, and open/transport-invariant format
- The system enables parallel reading of relevant pages through semantic search rather than slow, unreliable graph traversal that requires multiple tool calls
- Memoryfields scale with model improvements because they're based on simple file formats (Markdown, SQLite) that models already understand well
- The format is designed to be portable across systems, not locked to specific harnesses or agents, with a canonical archival format as zipfiles
- The author provides tooling and spec for implementation, and argues this approach works better for AI agents than complex multi-stage pipelines

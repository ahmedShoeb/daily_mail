## Key Points

Starting August 14, 2024, new Claude Code sessions on Pro, Max, and Team plans will default to auto mode
Auto mode balances user convenience with safety by routing tool calls through a classifier that blocks irreversible, destructive, or external actions
Users approve 97% of permission prompts manually, suggesting reflexive clicking rather than careful review
In testing with 1,053 paid testers, humans caught dangerous commands only 13.6% of the time while auto mode blocked 89%
Manual approval sessions contained serious unintended harm more than twice as often as auto mode sessions (6.3% vs 2.4%)
Teams and Enterprise adopters using auto mode ship about 25% more PRs
The classifier overhead will no longer be charged for Pro, Max, and Team plans effective immediately
Auto mode will remain opt-in for Enterprise users and API customers initially, with plans to make it default within a month
The auto mode classifier adds defense against prompt injection attacks - in tests, none of 720 attack attempts succeeded against Claude Fable 5, Opus 5, or Sonnet 5
Companies like Adobe, Nuro, Gusto, and Garner Health already run auto mode as their production default

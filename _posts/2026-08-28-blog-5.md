## Key Points

- Perplexity is launching Portable Computer, a fully local version of its AI agent platform that runs entirely on users' existing hardware
- Developed in partnership with Nvidia, it runs on DGX Spark desktop supercomputers and Linux machines with Nvidia RTX GPUs (24GB VRAM minimum)
- All work happens locally by default, with zero token costs - the system asks permission before escalating to cloud models when needed
- Portable Computer packages the full AI stack (models, agent harness, inference engine, tools, connectors) into a single easy-to-use application
- The system uses specialized models like Qwen 3.8 27B and Perplexity's post-trained PPLX 27B, with Nemotron 3.5 Lightning coming soon
- Perplexity's research shows their custom-designed agent harness significantly outperforms general-purpose alternatives on local models
- The launch addresses token economics for AI agents - local execution eliminates cloud API bills for extended agentic workloads
- The hybrid approach allows local models to escalate to frontier cloud models when needed, recovering most performance at lower cost
- Current launch is for Linux with Pro/Max/Enterprise subscribers, Windows support coming in September
- This represents a strategic shift moving serious AI agent workloads from cloud to local devices for cost, privacy, and control benefits

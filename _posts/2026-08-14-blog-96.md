## Key Points

1. Nvidia released Nemotron 3.5 Lightning, a 30-billion-parameter open mixture-of-experts model built for specialized agent tasks, alongside NeMo Switchyard, an open-source routing library
2. Switchyard dynamically routes each step of an AI agent workflow to the most appropriate model, allowing models to change mid-task as the agent's state shifts
3. Nvidia claims the combination delivers frontier-level task completion while cutting benchmark costs to roughly a third of running a single frontier model like Opus 4.8 alone
4. Nemotron 3.5 Lightning delivers up to 4x faster output than comparable models in its class, completing agentic tasks roughly 30% faster than Qwen3.6-35B at matching accuracy
5. Switchyard can evaluate model verbosity (token output) and use that prediction to steer work toward cheaper options before making the API call
6. Early testing results show significant cost reductions: LangChain reported 74% cost reduction across 145 multi-turn tasks, while Ramp cut costs 58% and runtime 33%
7. The router integrates with existing frameworks including Cognition, LangChain, Nous Research, Kong, LiteLLM and OpenRouter
8. Nvidia is betting that owning both the model layer and routing layer under one open license gives them a competitive advantage over router-only or model-only competitors
9. The timing puts Nvidia in a crowded open-weight market with recent releases from Alibaba, Moonshot, Zhipu, DeepSeek, and Meta's Muse Glimmer
10. This approach represents a shift where enterprises need dynamic per-step routing based on live signals rather than fixed model assignments set at design time

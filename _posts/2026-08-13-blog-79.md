## Key Points

- Meta has introduced Muse Glimmer, a 30-billion-parameter open-source agentic model optimized for local device deployment
- The model is released under Apache 2.0 license and can run on consumer hardware like Mac or PC with a single GPU
- Muse Glimmer is designed for always-on local agent workflows including function calling, local coding, and LLM-as-a-judge evaluation
- It achieves strong performance on agentic benchmarks like DeepSearch QA, MCP-Atlas, and SWE-Bench compared to similar-sized models
- Key capabilities include reliable tool use, multi-step reasoning, failure recovery, multimodal understanding, and support for over 100 languages
- The model uses quantization to shrink from 55GB to under 20GB, making it practical for consumer hardware
- Includes speculative decoding via a DFlash drafter model for faster generation while maintaining output quality
- Available now on Hugging Face with integrations coming soon for llama.cpp, MLX, ExecuTorch, Ollama, and other platforms
- Designed to work with existing agentic orchestration patterns like OpenClaw
- Partners include AMD, Arm, Dell, Intel, and NVIDIA for device optimization

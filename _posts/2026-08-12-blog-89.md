## Key Points

- LangChain has launched Managed Deep Agents in public beta, allowing developers to deploy agents to production without managing infrastructure
- Developers can author Deep Agents in Python or TypeScript, test locally, and deploy with a single command using LangSmith's managed runtime
- The platform handles production infrastructure including persistence, memory mounts, sandbox lifecycle, and deployment while developers control models, instructions, and tools
- Deep Agents provides an open source agent harness for common agent patterns like tool calling, file management, context management, subagent delegation, and human approval workflows
- Managed Deep Agents builds on LangSmith Deployment Agent Server with production primitives including durable execution, streaming, sandboxes for code execution, and persistent memory
- The system supports channels for integration with tools like Slack, allowing agents to meet users where work happens
- Teams can use Harbor evals without setup work to verify agent behavior and track actions taken during execution
- The platform includes identity and authentication systems for multi-user agents with OIDC provider support
- Companies like Fullstory and stealth-mode startups are already using Managed Deep Agents to deploy agents faster by focusing on business logic instead of infrastructure
- The public beta is currently available for LangSmith Cloud in the US region with additional regions coming later

## Key Points

- Introduces a simple method to split git commits using 'git history split ${REF}' command
- The tool guides users hunk by hunk to select what to include in the first commit
- Automatically opens editor for both the first and second commit messages after selection
- Notes that this approach is much simpler than previous cumbersome methods
- References a Stack Overflow discussion where the simpler approach only has 2 upvotes compared to 2656 for the older cumbersome method

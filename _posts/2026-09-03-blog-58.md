## Key Points

- Runway introduces Solaris, the first Interface World Model that generates interactive interfaces in real-time frame by frame
- Solaris eliminates the need for intermediate code representations by directly generating the visual interface as users interact with it
- The system combines an LLM for reasoning and a video generation model for rendering, creating responsive applications that evolve continuously
- Unlike traditional interfaces, Solaris is entirely visual, alive (constantly evolving), and open-ended (not limited to predefined workflows)
- Solaris generates frames autoregressively at interactive speeds, overcoming traditional video diffusion model latency issues
- In user studies, Solaris was preferred 61% of the time for following instructions and 71% for natural behavior compared to coded interfaces
- The model faces challenges with stable text generation, maintaining trust in commercial applications, and long session coherence
- Solaris represents a shift from fixed app paradigms to dynamic, personalized interfaces that adapt to user intent in real-time
- Potential applications include virtual storefronts, adaptive tutorials, and environments that reshape around individual user interactions
- Runway is working with key partners for public launch and is offering early access to interested parties

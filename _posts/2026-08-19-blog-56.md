## Key Points

- Google Antigravity introduces Custom Agents in Antigravity 2.0 and CLI to address limitations of general-purpose coding assistants
- Custom agents are specialized, file-based configurations that define specific roles with scoped instructions, tools, and constraints
- They solve issues of context window bloat and lack of specialization by providing predictable, focused assistants for specific tasks
- Custom agents complement existing skills and dynamic subagents by offering additional optimization layers
- Available in Antigravity 2.0 Desktop App and CLI with Markdown/YAML file format stored in workspace or global config directories
- Unique features include execution symmetry (can run as main agent or subagent), scoped safety policies for command execution, and curated skills/toolsets
- Agents can be committed to project repositories for team-wide standardized workflows without manual setup
- Designed for the agent-first era of software development where engineering shifts from writing code to orchestrating agents

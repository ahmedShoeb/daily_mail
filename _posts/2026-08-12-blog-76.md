## Key Points

- Cursor Router uses an intelligent system to automatically select the best AI model for each coding task based on complexity and performance requirements
- The system has two main configurations: Auto Intelligence (aims for Fable-level satisfaction at 68% lower cost) and Auto Balance (outperforms Opus at 41% lower cost)
- Uses 'Compass' - a complexity predictor that estimates whether a task is simple enough for cost-efficient models or needs frontier models
- Built a data-driven taxonomy from real developer traffic across domains (backend, frontend, database), tasks (bug fixes, testing, commands), and modifiers (visual-heavy changes, product questions)
- Different models excel at different tasks: Grok for routine work, Sol for planning/comprehension, Opus for execution-heavy work, Fable for debugging/visual implementation
- The routing algorithm combines complexity prediction with performance-based routing, only upgrading to better models when there's 75% confidence in improved performance
- System has improved since launch, adding Opus 5 and enhancing predictions, delivering better cost-performance tradeoffs
- Goal is to keep pace with model frontier improvements, making the system more adaptive over time

## Key Points

- Warp's Agent Memory is a research preview feature providing persistent memory system that lives on Warp and is shared across supported agent harnesses
- Memory creation and retrieval are asynchronous - they run in background without consuming tokens or adding latency to active tasks
- Supports cross-harness memory sharing across Warp Agent, Claude Code, Codex, and other agent harnesses when running as cloud agents
- Memory is organized into stores: personal stores (user-owned), agent stores (agent-owned), and team stores (team-owned)
- New agents get auto-memory by default - a dedicated memory store that builds long-term memory from first run
- Automatic memory creation extracts durable facts, learnings, and outcomes from conversations after they end
- Features include traceability (tracking memory sources) and auditability (recording memory changes over time)
- Stores can be attached to agents with read-only or read-write access, each with per-store instructions
- Future capabilities include programmatic API access and self-hosting support for compliance requirements
- Currently in research preview - teams can join waitlist for access during this preview phase

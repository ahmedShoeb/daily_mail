## Key Points

- Vercel Connect replaces long-lived tokens with runtime-requested tokens that expire automatically, addressing credential sprawl for AI agents and applications
- The service moves credentials from static storage in environments to on-demand tokens that are scoped to specific tasks and expire after use
- System now features 100+ preset connectors for popular services like Slack, GitHub, Shopify, Notion, and Salesforce
- Eliminates the need for apps to store provider secrets, reducing the risk of accidental credential exposure
- Tokens can be scoped at different levels (app-level vs. user-level) with fine-grained permissions depending on the service
- Now includes governance features like fine-grained RBAC controls, audit logs, and token observability for enterprise use
- Supports various environments including custom environments, Vercel Workflows, eve agents, and Chat SDK applications
- Available on all Vercel plans with Hobby plan including 500 token requests and 1,000 triggers per month free
- Provides trigger-based event handling without storing secrets in apps, enabling event-driven workflows
- Built around a single `getToken` API call with adapters for different frameworks and SDKs

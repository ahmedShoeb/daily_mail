## Key Points

- Cursor is launching Origin, a new integrated code hosting platform available in early beta for all paid plans
- Origin includes essential features: repos, pull requests, code browsing, and GitHub sync with agent-native features coming soon
- Users can create new repos directly in Cursor and push code through a CLI, with codebase-specific URLs
- GitHub integration allows syncing existing repos, with real-time updates and bidirectional sync for pull requests
- Agents are integrated into every repo, allowing AI-powered code assistance, changes, and PR management
- App ecosystem includes integrations with Vercel, Depot, and Buildkite for preview deployments and CI/CD workflows
- Repos support settings for access management, sync status, and app connections
- Rollout begins immediately for paid users (except enterprise orgs that opt out)
- The platform positions code, PRs, and AI agents together in one unified workflow environment

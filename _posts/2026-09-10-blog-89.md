## Key Points

- hip-agent is a 'harness in prompt' designed specifically for AI agents, not humans, unlike existing coding harnesses like Claude Code and Codex
- The core idea is to keep the harness minimal (~200 lines of Python) so it can fit in the prompt and allow agents to understand and modify it
- The system treats the OS as the runtime, using environment variables for configuration and shell commands for actions
- It uses existing protocols: plugins follow Agent Plugins, hooks use Claude Code's hook contract, and conversations are Codex CLI session files
- The design allows agents to spawn subagents naturally by calling the agent from within a shell command, inheriting the environment
- A key advantage is that the harness is 'repairable' - sufficiently smart models that understand their harness can work around its limits or modify them
- Performance on DeepSWE benchmark (113 tasks) was comparable to Codex CLI: 73/113 resolved (64.6%) vs 72/113 (63.7%)
- The author argues model providers should ship minimal native reference harnesses separate from user-facing products to make model evaluation more accurate
- This approach enables users to test new models easily by having existing agents run them as subagents

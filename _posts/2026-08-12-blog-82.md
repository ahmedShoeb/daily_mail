## Key Points

- Users can now bundle multiple agent skills into shareable packs on skills.sh
- Packs can be built from various sources including community skills, local folders, zips, and public/private GitHub repositories
- Each pack is unlisted but has its own unique URL for sharing
- Packs can be shared with individuals or entire teams to standardize skills across projects
- Installation is simple with a single command: npx skills add https://skills.sh/p/<pack-id>
- Packs can be updated to their latest version using: npx skills update
- Users can explore and create packs at skills.sh/packs

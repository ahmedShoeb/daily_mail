## Key Points

- An abliterated (refusal-removed) MLX build of Qwen's Qwen3.8-27B model optimized for Apple Silicon
- Quantized to 2/4/6/8-bit precision with the 4-bit build recommended as the default option
- Removed safety alignment - will comply with harmful/unethical requests that original Qwen3.8-27B would refuse
- Intended strictly for legitimate research: interpretability, AI-safety studies, red-teaming, and controlled experiments
- Vision capabilities preserved including 262K token context length, thinking control, and tool-calling features
- Four quantization options available: 8-bit (near-lossless), 6-bit (excellent), 4-bit (very good - recommended), 2-bit (severely degraded)
- Warning: 2-bit quantization collapses generation quality with repetition loops and garbled output
- Supports multiple platforms: MLX, LM Studio, Pi, Hermes Agent, Atomic Chat, and OpenClaw
- Requires users to add their own safety and moderation layers before any deployment
- Model available as API and includes vision tower, norms and conv layers kept in BF16 while language-model weights are quantized

## Key Points

Miles v0.1 is a full-stack production-ready system for frontier reinforcement learning post-training, serving as a successor to their earlier Miles release
The system features a fully asynchronous RL loop with three main stages: rollout (using SGLang engines), training (with NVIDIA Megatron-LM or FSDP backends), and weight updates
Miles supports agentic RL workflows with multi-turn sessions, tool execution, sandboxed environments, and token-faithful trajectory capture
The system enables low-precision training with support for NVFP4, MXFP4, MXFP8, and FP8 precision formats for improved efficiency
Miles provides day-0 support for frontier models including Kimi-K3, DeepSeek-V4, Inkling, Qwen3.8, and NVIDIA Nemotron 3 Ultra
Key innovations include Token-In-Token-Out (TITO) for preserving exact token IDs, Rollout Routing Replay (R3) for MoE models, and efficient weight synchronization methods
The system supports multiple training paradigms beyond core RL, including LoRA RL, On-Policy Distillation (OPD), supervised fine-tuning, and Zero-KL Alignment
Miles demonstrates multi-hardware support running on both NVIDIA (A100 through GB300) and AMD (MI300X through MI355X) GPUs
An example shows training GLM-5.2 744B-A40B model on terminal-use coding tasks using 64 NVIDIA GB300 GPUs with fully asynchronous RL
The system emphasizes code quality principles with modular, typed interfaces making it easy to read and extend for custom RL training loops

## Key Points

- Cursor launched Origin, its own code hosting platform, to paid users on Monday, coinciding with a major GitHub outage that lasted 6 hours and 42 minutes
- Origin allows teams to host codebases and work with pull requests within Cursor's editor, with AI agents operating in the same surface as the code
- Origin doesn't require leaving GitHub - it connects to GitHub organizations and syncs pull requests bidirectionally while keeping GitHub as the source of truth
- The platform includes integrations with Vercel (for preview deployments), Depot and Buildkite (for CI/CD), with compatibility for existing GitHub Actions workflows
- AI agents have created a new bottleneck in software development: 35% of pull requests merged inside Cursor were opened by agents running autonomously
- GitHub has faced significant reliability issues with 257 incidents between May 2025-April 2026 and 48 major disruptions
- Cursor was recently acquired by SpaceX for $60 billion in an all-stock deal and now operates within SpaceXAI division
- Origin launched as opt-out rather than opt-in for enterprise customers, raising questions about default deployment
- Security concerns exist, including a previous vulnerability that Cursor declined to patch and questions about data handling under SpaceX ownership
- The article recommends enterprises evaluate exit strategies and understand terms before authoritatively moving code to Origin

## Key Points

- Author developed Deckard, a Chrome extension for local AI text detection that runs in the background
- Automatically scans websites for AI-generated text without sending data to third-party services
- Uses a local model (EditLens RoBERTa-large — community INT8) with 2.48% human false positive rate and 56.06% AI detection rate
- Model takes about 400MB-1.2GB of memory while active and turns off after 5 minutes of inactivity
- Significantly less accurate than commercial solutions like Pangram (99.66% detection rate)
- Designed as early investment in AI detection tools that will improve as models get better over time
- Uses Chrome's native messaging system instead of local HTTP server for communication
- Author believes AI detection models will improve and small local models will eventually become good enough for everyday use
- Addresses the underserved niche of automated AI text detection in browsers

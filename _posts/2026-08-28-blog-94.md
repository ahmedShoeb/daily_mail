## Key Points

- Apple announced two new chips: M6 (first 2nm Apple chip) and M5 Ultra (most powerful Apple chip ever)
- M6 debuts in new Mac mini with 12-core CPU, 12-core GPU, Dual 16-core Neural Engine, and up to 170GB/s memory bandwidth
- M5 Ultra debuts in new Mac Studio with quad-die architecture (first for Apple silicon), up to 36-core CPU, 80-core GPU, and 1.2TB/s memory bandwidth
- M6 offers up to176% faster performance than M1 and up to 20% faster than M5 for multithreaded workloads
- M5 Ultra provides up to 1.3x higher multithreaded performance than M3 Ultra with 50% more memory bandwidth
- Both chips feature Neural Accelerators in GPU cores for enhanced AI compute, with M6 offering nearly 30% more peak GPU compute for AI vs M5
- M5 Ultra supports up to 512GB unified memory, enabling massive AI models to run entirely on device
- Apple's developer frameworks optimize performance across CPU, GPU, and Neural Engine for AI workloads
- M5 Ultra features next-generation UltraFusion technology connecting two dual-die M5 Max chips with 4.4TB/s inter-die bandwidth
- Both chips support Apple Intelligence features with on-device AI processing for security and privacy

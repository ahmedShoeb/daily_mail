## Key Points

- Microsoft has released MAI-Code-1.1-Flash, a new coding model now in production in GitHub Copilot
- The new model is significantly more efficient - 25% greater token efficiency and uses 25% fewer tokens to complete tasks
- It's priced at a quarter of the cost compared to the model launched in June at Microsoft Build
- The model shows a 22% improvement on Terminal-Bench 2.1 for GitHub Copilot CLI tasks
- There's a 15% improvement on .NET tasks based on developer feedback
- In production, code survival rates rose by 4% and return visits increased by 9%
- The model was optimized using hundreds of thousands of reinforcement-learning environments in GitHub Copilot
- Microsoft emphasizes their iterative approach: 'ship, learn, improve, repeat' as the 'MAI hill climbing machine'
- The improvements were driven by developer feedback focusing on CLI tasks and .NET performance
- The team is inviting developers to try the new model and provide feedback for future improvements
